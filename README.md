# AI Meglio — ドット絵アニメーション AI編集スタジオ

ブラウザで動くドット絵アニメーションエディタです。手持ちのドット絵キャラ画像を読み込み、そのテイストを崩さずに歩き・走り・攻撃などのモーションをAIで生成し、おかしい部分（足の左右など）を範囲指定の日本語指示や手描きで高速に直せます。

設計の詳細は [DESIGN.md](./DESIGN.md) を参照してください。

## このツールへの期待値（重要）

一発でプロ品質のモーションが出るツールではありません。このツールの価値は、**テイストが構造的に崩れない土台**（パレットロック・ベースフレーム・アンカリング・ロック領域）の上で、

> モーション生成 → 逸脱メーターで確認 → 範囲指定して修正指示 → 手描き微調整

というループを**数秒単位で回せる**ことにあります。生成結果はあくまで叩き台として、修正タブと手描きツールで詰めていくワークフローを前提に設計されています。

## 特徴

- ビルドステップ無し。Node.js の `node:http` と vanilla JS + Canvas API のみで構成。
- CDN・外部ライブラリを一切使わない。GIFエンコーダも自前実装。
- ドット絵を「パレット番号のテキストグリッド」として表現し、AIには参考用PNG画像とテキストグリッドの両方を渡す。出力は構造化JSON（差分パッチ）で受け取り、再生成ではなく確定的な差分編集を行う。

## セットアップ

```bash
npm install
```

依存パッケージは `@anthropic-ai/sdk` のみです。

## 起動

### 実際にClaude APIを使う場合

```bash
export ANTHROPIC_API_KEY=sk-ant-...
npm start
```

デフォルトで `http://localhost:8787` で起動します。

### Claude Code CLI モード（APIキー不要）

Claudeサブスクリプション（Claude Code）ユーザーは、APIキーなしでAI機能を使えます。

```bash
# 1. Claude Code をインストール（未インストールの場合）
npm install -g @anthropic-ai/claude-code

# 2. ログイン（初回のみ。対話モードを開いて /login）
claude

# 3. CLIバックエンドで起動
BACKEND=cli npm start
```

注意:

- **サブスクリプションの利用上限を消費します**（AI実行のたびに Claude Code の1リクエストとしてカウントされます）。
- **画像は渡されません**（テキストグリッドのみでAIが判断します。見た目依存の指示は精度が下がる場合があります）。
- モデルは `CLI_MODEL`（既定 `sonnet`）で指定します。本文ストリーミングは行われず、完了時に結果がまとめて届きます（実行中は経過秒数付きの進捗表示のみ）。
- **広範囲の修正は時間がかかります。矩形選択で範囲を絞って指示するのが最速です**（1セル程度の修正は数十秒、フレーム全体に及ぶ修正は数分かかることがあります）。タイムアウトは既定300秒で、`CLI_TIMEOUT`（秒）で延長できます。時間がかかりすぎる場合は `CLI_MODEL=haiku` も試してください。
- 「全フレーム」スコープの修正は、サーバー側で自動的にフレームごとの呼び出しに分割され（並列2）、進捗が「フレーム 2/5 完了」のように表示されます。この分割モードではフレーム追加（中割り等）は行えないため、中割りは「現在のフレーム」スコープで指示してください。
- 現在のバックエンドはキャンバス下部に表示されます（「バックエンド: API / Claude Code CLI / MOCK」）。

### MOCKモード（APIキー無しで動作確認）

```bash
MOCK=1 npm start
```

APIを呼ばず、選択範囲（選択が無ければフレーム全体の中央8×8）をパレット最後の色で塗るパッチを2秒かけて疑似ストリーミングで返します。UI・SSE通信・パッチ適用の動作確認用です。`MOCK=1` は `BACKEND` 指定より優先されます。

## 環境変数

| 変数 | 既定値 | 説明 |
|---|---|---|
| `PORT` | `8787` | サーバーのリッスンポート |
| `EXPORT_ROOT` | 未設定 | ゲームリポジトリのパス。設定すると「ゲーム書き出し」からこの配下に直接書き出せる（未設定時は /api/export 無効） |
| `BACKEND` | `api` | `api` = Anthropic API / `cli` = ローカルの Claude Code CLI |
| `MODEL` | `claude-opus-4-8` | 使用するClaudeモデル（BACKEND=api） |
| `CLI_MODEL` | `sonnet` | 使用するモデル（BACKEND=cli）。遅い場合は `haiku` を推奨 |
| `CLI_TIMEOUT` | `300` | CLI呼び出しのタイムアウト秒数（BACKEND=cli） |
| `EFFORT` | `medium` | 構造化出力の `output_config.effort`（BACKEND=api） |
| `MOCK` | 未設定 | `1` を指定するとAPIを呼ばずモック応答を返す（BACKENDより優先） |
| `ANTHROPIC_API_KEY` | — | Anthropic APIキー（BACKEND=api のとき必要。MOCK=1 / BACKEND=cli では不要） |

## 使い方

### 基本フロー（元画像ベースのモーション生成）

1. ヘッダーの「画像を開く」で手持ちのドット絵画像（PNG / GIF の1枚目 / WebP）を読み込みます。
   - 8倍拡大などの**拡大済み画像でもOK**。同色ラン長のGCDから実寸（例: 256×256 → 32×32）を自動検出し、ダイアログで確認できます（「幅x高さ」を入力すれば手動上書き可）。
   - 出現色は頻度順に抽出され、32色（透明含む）を超える場合は上位31色+透明に量子化されます（各ピクセルはRGB距離の最近色へ）。
   - 読み込んだ画像は **frame 0 = ベースフレーム**（タイムラインに「基準」バッジ）になります。
2. 顔など絶対に変えたくない部分があれば、矩形選択して「この範囲をロック」。ロック領域（半透明赤・複数可）内のセルは、AIが何を返してもサーバー側で**ベースの値に強制上書き**されます。
3. AIパネルの「モーション生成」タブでプリセット（歩き / 走り / 攻撃 / 待機 / ジャンプ / カスタム）とつまみ（フレーム数 2〜12、動きの大きさ、上下バウンス、向き）を選んで実行します。生成結果は「既存フレームを置き換え」か「末尾に追記」を選べます。
4. 各フレームのサムネイル下の**逸脱メーター**（ベースフレームとの差分率%、40%超は警告色）で、動きとして妥当な差分か、テイスト崩れかを一目で確認します。「差分ビュー」トグルで変更セルをマゼンタ枠でハイライトできます。
5. おかしい部分は「修正」タブで範囲指定+日本語指示（例:「右足が前のはずなのに左足が前になっている。直して」）、または手描きツールで直します。

### エディタ操作

1. サーバー起動直後はサンプルのドット絵（32×32・8色・上下にバウンドする2フレーム）が読み込まれています。
2. 左のツールパネルでペン・消しゴム・塗りつぶし・矩形選択・スポイトを切り替えてドット絵を編集できます。ホイールでズーム、パレットのダブルクリックで色を変更できます。
3. 矩形選択ツールでキャンバス上をドラッグすると範囲選択ができます。選択すると右のAIパネルに「対象: フレームN の (x,y)〜(x2,y2)」と表示されます。
4. 「修正」タブで対象スコープ（選択範囲のみ / 現在のフレーム / 全フレーム）を選び、指示テキストエリアに日本語で指示を書いて「実行」（または Cmd/Ctrl+Enter）を押します。
   - 指示例: 「腕の振りをもっと大きく」「輪郭のジャギーを滑らかに」「フレーム1と2の間に中割りを追加」「全体を夕暮れの色調に」「この範囲の剣を炎の剣にして」
5. 生成中はストリーミング進捗が表示され、「中断」でいつでも止められます。パッチが適用されると、変更されたセルが約1秒間ハイライトされ、下部の再生プレビューに即座に反映されます。
6. 気に入らない結果は Cmd/Ctrl+Z で即座に取り消せます（Undo/Redo はプロジェクト全体のスナップショット、最大50件）。
7. タイムラインでフレームの追加・複製・削除・並び替え、fps変更、再生/停止ができます。
8. ヘッダーメニューから、プロジェクトのJSON保存/読込、スプライトシートPNG書き出し、アニメーションGIF書き出しができます。

### リグモード（2Dパーツリグ）

動きの機構的な正しさを骨格（リグ）で保証し、絵は元素材のドットをそのまま使い、AIには継ぎ目の清書だけをさせるモードです。「AIが足の左右を描き間違える」問題を原理的に排除します。

1. AIパネルの「リグ」タブで、矩形選択→「パーツとして登録」（名前・pivot=回転支点・z順・親を設定）するか、「AI自動分割」でパーツの下書きを作ります。パーツはベースフレームから切り出されます。
2. プリセット（歩き4f / 走り6f / 攻撃3f / 待機2f / ジャンプ4f）とつまみ（振り幅 0.5×/1.0×/1.5×、バウンス、フレーム数=線形補間）を選んで「フレーム生成」。モーションは**ハードコードされたキーフレームテーブル**（左右脚の逆位相・接地フレームで胴体最低・腕は脚と逆位相、をテーブル値として直接埋め込み）から生成され、パーツをz順・pivot周りの回転（最近傍・15°刻み）・親変換の継承つきで合成した通常のフレームとしてタイムラインに入ります。
3. 回転ジャギーや継ぎ目の隙間は「AI清書」で修正します。変更許可セルは「合成時に変化したセルの周囲2px」に限定され、許可外への編集はサーバー側で破棄されます（フレームごとに並列リクエスト）。
4. 生成後はフレームを選んでパーツをドラッグ移動（「キャンバスでドラッグ移動」ON時）や ±1px・±15° ボタンで微調整できます。逸脱メーター・差分ビュー・修正タブ・手描きツールもそのまま使えます。

### テイスト保持の仕組み

| 機構 | 内容 |
|---|---|
| パレットロック | AI出力はパレットindexのグリッドのみ。モーション生成モードでは `paletteChanges` をサーバー側で破棄するため、色は定義上1色も変わらない |
| ベースフレーム・アンカリング | すべてのAIリクエストにベースフレームのグリッドを「唯一の正」として同梱。新規フレームはベースのコピーを起点に生成される |
| ロック領域 | ロック矩形内のセルへの編集はサーバー側でベースの値に強制上書き |
| 逸脱メーター | 各フレームのベースフレームとの差分率%を常時表示（40%超は警告色） |
| 差分ビュー | 変更セルだけをマゼンタ枠でハイライト |

### ゲーム制作レイヤー（タグ・プロファイル・書き出し）

ツールを「単発のGIF作成」から「ゲームアセットの量産ライン」として使うための機能群です。

- **アニメーションタグ（Aseprite方式）**: タイムライン上部のタグバーで、1プロジェクト内に walk / attack などの複数モーションをフレーム範囲として定義できます（タグごとに fps / loop 設定）。タグをクリックするとその範囲だけがループ再生され、GIF書き出し・ゲーム書き出しの対象になります。モーション生成・リグ生成の結果は自動で新しいタグになります。フレームの挿入/削除時はタグ範囲が自動補正されます。
- **配色バリエーション（パレットスワップ）**: 「修正」タブの「配色バリエーション」ボタンで、パレットの色だけをAIに変えさせます（例:「毒々しい緑基調に」）。軽量モードなのでCLIバックエンドでも高速です。候補をプレビューして「適用」するか「バリエーションとして保存」でき、保存したバリエーションは書き出し時に全色違い分のシートが出力されます。
- **ゲームプロファイル**: `public/profiles/*.json` に書き出し規約（exportDir / format / scale / naming / requiredTags / mirror）を定義します。ヘッダ下のバーでプロファイルを選ぶと、**必要タグのチェックリスト**（idle✓ walk✗ …）が表示され、✗をクリックするとそのモーションの生成設定に直行します。
- **ゲーム書き出し**: 「ゲーム書き出し」ボタンから、`sheet+json`（1枚のシートPNG + Aseprite json-array 互換メタJSON。frameTags 付きで大抵のエンジンが読めます）/ `strip-per-tag`（タグごとの横ストリップ）/ `frames`（連番PNG）を書き出せます。`scale` で整数拡大、プロファイルが `mirror: "export"` なら左右反転タグ（walk_left 等）もタグ単位のON/OFF付きで出力します。書き出し先はブラウザダウンロードか、`EXPORT_ROOT=<ゲームリポジトリ> npm start` で起動していればリポジトリへの直接書き出し（`/api/export`。EXPORT_ROOT 配下限定・パストラバーサル拒否）が選べます。
- **ゲームビュープレビュー**: AIパネル下部で背景画像（ゲームのスクリーンショット等）を読み込み、×1〜×4のゲームスケールで移動ループ再生して実機の見え方を確認できます（背景はセッション限りで保存されません）。

## 開発メモ

- サーバーは Express 等を使わず `node:http` のみで実装しています（`server.js`）。
- Claude API 呼び出しは `@anthropic-ai/sdk` の `messages.stream()` を使い、`thinking: { type: "adaptive" }` と `output_config.effort` / `output_config.format`（JSON Schema による構造化出力）を利用します。`temperature` 等のサンプリングパラメータやアシスタントprefillは対象モデルでは使用できないため送っていません。
- サーバー側でパッチの座標・文字種を検証し、`scope=selection` のときは選択矩形外への `edits` を切り捨てて適用します（`newFrames` と `paletteChanges` はスコープに関係なく許可）。
- フロントエンドはビルド不要の ES Modules（`public/app.js` がエントリポイント）。
